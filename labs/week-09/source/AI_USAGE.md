## ครั้งที่ 1

**ถามอะไร**
วิธีทดสอบ Constraint ในฐานข้อมูล (CP25) หาสาเหตุที่ทดสอบ Foreign Key แล้วไม่ขึ้น Error ตามที่ต้องการ พร้อมขอชุดคำสั่ง SQL สำหรับจำลอง Error ทั้ง 5 รูปแบบ และวิธีระบุ Path รูปภาพข้ามโฟลเดอร์ใน Markdown

**AI ตอบว่าอย่างไร (สรุปสั้น)**
ชี้แจงว่า SQLite ปิดการตรวจ Foreign Key เป็นค่าเริ่มต้น ต้องเปิดด้วยคำสั่ง PRAGMA foreign_keys = ON; และต้องเลี่ยงการใช้ Primary Key ซ้ำเพื่อไม่ให้ติด Error ด่านแรก พร้อมให้ชุดคำสั่ง SQL สำหรับทดสอบเงื่อนไขทั้ง 5 ข้อ และแนะนำการใช้ Relative Path (../evidence/ชื่อรูป.png) ในการดึงรูปภาพมาแสดง

**ใช้ส่วนไหน / แก้เองตรงไหน**
นำคำสั่ง SQL ไปรันใน VS Code เพื่อเก็บภาพหน้าจอผลลัพธ์ Error แล้วนำข้อความสรุปพร้อม Path รูปภาพไปบันทึกผลการทดสอบใน source/DATA_MODEL.md

## ครั้งที่ 2

**ถามอะไร**
ต้องการเปรียบเทียบความแตกต่างเชิงสถาปัตยกรรมและข้อดีข้อเสีย ระหว่างการเขียน Automated Test ฝังไว้ใน Source Code (เช่น การใช้เฟรมเวิร์ก `supertest` หรือ `jest`) กับการทดสอบ API ผ่าน Extension (เช่น Postman, REST Client หรือ Thunder Client) เพื่อเลือกใช้เครื่องมือให้เหมาะสมกับ Workflow

**AI ตอบว่าอย่างไร (สรุปสั้น)**
AI วิเคราะห์ว่า Extension เหมาะกับการทดสอบแบบ Manual (Exploratory Testing) ที่ต้องการเห็นผลลัพธ์ (Response) อย่างรวดเร็วในระหว่างการพัฒนา แต่การเขียน Test ไว้ใน Code (Automated Testing) จะมีข้อได้เปรียบระยะยาว คือสามารถรันซ้ำได้อัตโนมัติเมื่อมีการแก้ไขโค้ด (ป้องกัน Regression Bug) สามารถเขียน Assertion ตรวจสอบโครงสร้างข้อมูลและ Status Code ได้รัดกุมกว่า และรองรับการทำ CI/CD (Continuous Integration) ได้อย่างสมบูรณ์

**ใช้ส่วนไหน / แก้เองตรงไหน**
นำข้อสรุปเชิงวิเคราะห์ที่ได้ ไปประกอบการตัดสินใจและอธิบายเหตุผลในการเลือกใช้ Automated Test สำหรับการตรวจสอบ API Contract ของโปรเจกต์ เพื่อให้ระบบมีความน่าเชื่อถือและตรวจสอบย้อนหลังได้ง่ายขึ้น

**เข้าใจโค้ดที่ได้มาไหม** ✓ เข้าใจทั้งหมด ☐ เข้าใจบางส่วน ☐ ยังไม่เข้าใจ

## สรุป

- **ส่วนที่เขียนเองทั้งหมด:** การเขียนคิวรี (SQL Queries) พื้นฐานสำหรับการจัดการฐานข้อมูล, การสร้าง Test Cases เพื่อจำลองสถานการณ์และตรวจสอบ Data Integrity ตามเงื่อนไข (CP25), รวมถึงการรวบรวมหลักฐานและจัดทำเอกสาร `DATA_MODEL.md` ด้วยตนเอง
- **ส่วนที่ AI ช่วย:** การวิเคราะห์พฤติกรรมเชิงลึกและ Default Configuration ของ SQLite (เช่น การเปิด `PRAGMA foreign_keys` และลำดับการตรวจจับ Constraint), การเปรียบเทียบสถาปัตยกรรมการทดสอบระบบ (Automated Test vs. Extension) เพื่อหา Best Practice, และการแก้ปัญหา Formatting ในเอกสาร Markdown
