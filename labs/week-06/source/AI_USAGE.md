# AI_USAGE — LAB 06

บันทึกการใช้ AI ระหว่างทำงาน · **ใช้ AI ได้ แต่ต้องเป็นเจ้าของโค้ดที่ส่ง**

> ผู้สอนจะสุ่มถามจากโค้ดที่ส่ง — ถ้าอธิบายไม่ได้ คะแนนส่วนนั้นจะถูกทบทวน

---

## ครั้งที่ 1

**ถามอะไร**
ถามวิธีแก้ Error ตอนรันเซิร์ฟเวอร์ และปัญหาข้อมูลคำร้องหายไปหลังจากรีสตาร์ทเซิร์ฟเวอร์ (CP08)

**AI ตอบว่าอย่างไร (สรุปสั้น)**
บอกให้ลบ import { readFile } ที่ซ้ำกันออก และแนะนำให้เติม async/await พร้อมเรียกใช้ await persist() ในฟังก์ชัน create, remove และในฝั่ง Controller เพื่อบันทึกข้อมูลลงไฟล์ถาวร

**ใช้ส่วนไหน / แก้เองตรงไหน**
นำไปแก้ไขใน src/services/requestService.js และ src/controllers/requestController.js

**เข้าใจโค้ดที่ได้มาไหม** ✓ เข้าใจทั้งหมด ☐ เข้าใจบางส่วน ☐ ยังไม่เข้าใจ

---

## ครั้งที่ 2

**ถามอะไร**
ถามแนวทางการทำ Challenge 2 (เปลี่ยนสถานะคำร้องด้วย PUT) และวิธีแก้ Error 404 Not Found ตอนทดสอบยิง Postman

**AI ตอบว่าอย่างไร (สรุปสั้น)**
แนะนำวิธีเขียนฟังก์ชันอัปเดตสถานะและตรวจสอบเงื่อนไขสถานะที่ถูกต้อง และชี้ให้เห็นว่าเกิด Error 404 เพราะลืมเพิ่ม router.put('/:id', ...) ในไฟล์ตั้งค่า Route

**ใช้ส่วนไหน / แก้เองตรงไหน**
นำไปเขียนใน requestService.js, requestController.js และเพิ่มเส้นทางในไฟล์ src/routes/requestRoutes.js

**เข้าใจโค้ดที่ได้มาไหม** ✓ เข้าใจทั้งหมด ☐ เข้าใจบางส่วน ☐ ยังไม่เข้าใจ
