# B1 · บันทึกการแก้บั๊ก (กรอกให้ครบทั้ง 6 จุด)

> แต่ละบั๊กให้เขียน 4 อย่าง: ไฟล์ · บรรทัด · สาเหตุ (ทำไมทำงานผิด) · แก้อย่างไร
> เขียนด้วยคำของตัวเอง — จุดนี้จะถูกถามใน oral

## บั๊กที่ 1 — อาการ: Console เตือนสีเหลืองเรื่องรายการ
- ไฟล์/บรรทัด: RequestList.jsx บรรทัด 9
- สาเหตุ: ใน function ที่ใช่ .map ไม่มี key เพื่อระบุตัวตน
- แก้อย่างไร: เพิ่ม key = {request.id} ด้านหน้า request={request}

## บั๊กที่ 2 — อาการ: ตัวเลข "รอดำเนินการ" ในแผงสรุปไม่ตรงกับที่เห็น
- ไฟล์/บรรทัด: DashboardPage.jsx บรรทัด 47
- สาเหตุ: ในตัวแปร summary บรรทัด pending: โค้ดไปนับสถานะ completed แทนที่จะเป็น pending
- แก้อย่างไร: เปลี่ยนแค่คำว่า completed ของบรรทัด pending เป็น pending

## บั๊กที่ 3 — อาการ: กดตัวกรอง "รอดำเนินการ" แล้วได้รายการที่ไม่ใช่
- ไฟล์/บรรทัด: DashboardPage.jsx บรรทัด 55
- สาเหตุ: filter ใช้สัญลักษณ์ ในการเก็บข้อมูลผิด แทนที่จะเป็น === แต่ใช้ !== ซึ่งหมายความว่าเอา request ที่ไม่ตรงกับ statusFilter ใส่เข้าไปทั้งหมด
- แก้อย่างไร: เปลี่ยนเป็น ===

## บั๊กที่ 4 — อาการ: เปลี่ยน URL จาก REQ-001 เป็น REQ-002 แล้วข้อมูลไม่เปลี่ยน
- ไฟล์/บรรทัด: RequestDetailPage.jsx บรรทัด 28
- สาเหตุ: ไม่มีตัว requestId ทำให้เวลาเปลี่ยนข้อมูล react ไม่ยอมดึงข้อมูลใหม่
- แก้อย่างไร: เพิ่ม equestId

## บั๊กที่ 5 — อาการ: กด "ลบ" แล้วรายการยังอยู่ ต้องรีเฟรชถึงหาย
- ไฟล์/บรรทัด: DashboardPage.jsx บรรทัด 65
- สาเหตุ: setRequests(requests) ซึ่งเป็นการบอกให้ React อัปเดตหน้าจอด้วยตัวแปรชุดเก่า
- แก้อย่างไร: เปลี่ยน requests เป็น nextRequests

## บั๊กที่ 6 — อาการ: กด "Reset Demo Data" แล้วหน้าพัง/ว่างเปล่า
- ไฟล์/บรรทัด: DashboardPage.jsx บรรทัด 65
- สาเหตุ: ใน function handleReset ที่มี astnc นำหน้าแต่กลับไม่มี await เพื่อรอให้หลังบ้านส่งข้อมูลกลับมาทำจึงทำให้หน้าเว็บขาว
- แก้อย่างไร: เพิ่ม await หน้า resetRequests()
